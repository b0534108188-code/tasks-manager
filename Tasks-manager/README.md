# Task Manager Pro 📋

A modern, intuitive task management application built with pure HTML, CSS, and JavaScript.

## ✨ Features

- ✅ **Task Management** - Create, edit, delete, and organize tasks
- 🎯 **Priority Levels** - High, Medium, Low priority classification  
- 📅 **Due Dates** - Track deadlines for your tasks
- 🔁 **Recurring Tasks** - Automatic task creation (daily, weekly, monthly)
- 🚫 **Task Blocking** - Mark tasks as blocked
- 📊 **Real-time Statistics** - Overview of task status
- 🎨 **Filters** - View by priority, status, or blocked state
- 💾 **Export/Import** - Backup and restore as JSON
- 🔗 **Share Links** - Share task lists via URL
- 🎯 **Drag & Drop** - Reorder tasks easily
- 💬 **Comments** - Add notes to any task
- 📱 **Responsive Design** - Works on all devices

## 🚀 Quick Start

Simply open `index.html` in your web browser! No installation or server required.

## 💾 Data Storage

All data is stored locally in your browser's `localStorage`. Your tasks stay private and are never sent to any server.

## 🛠️ Technical Details

- Pure HTML, CSS, and JavaScript
- No dependencies or frameworks  
- Works offline
- localStorage for data persistence
- Modern CSS with Grid and Flexbox
